# PlugClaw: Portable Android OpenClaw Hardware for Phone and Computer
PlugClaw is a thumb-sized portable OpenClaw device. It runs on PlugOS, a security-focused system built on stock Android, and ships with its own processor, memory, and storage. Plug it in and it works right away across platforms.

# What Is PlugClaw (Form and How It Works)
In short: PlugClaw equals a standalone Android compute stick, an isolated OpenClaw agent, and a controlled channel for operating the Android interface.
The device carries its own processor, memory, encrypted storage, and the PlugOS security system, all wrapped in an aluminum shell that feels solid in the hand. PlugOS and OpenClaw work as a pair: the agent reaches its decisions inside an isolated virtual machine, a private sandbox, and then drives the Android interface through a controlled channel. Hardware, system, and agent stack into three layers that let a local AI agent run on its own inside a real mobile app ecosystem, doing more than trading chat messages or handing over suggestions.

Pull PlugClaw out of one phone and plug it into another computer, and your workspace, skills, and memory stay exactly as they were. Switching devices never breaks your setup, which is the core value of a portable cross-platform device. It works with Android, iPhone, iPad, Windows, macOS, and Linux hosts. PlugClaw is essentially a portable AI workstation, and the host machine only handles display and input.

# What PlugClaw Can Do (A GUI Agent That Runs Real Apps)
The core capability: the AI agent taps, swipes, and scrolls the way a person would, and drives apps straight from the Android ecosystem.
Running on PlugOS, PlugClaw uses an Android GUI agent and the Android-Use interface to let AI operate apps directly:
Open social apps, gather the trending topics, draft a briefing in your voice, and publish it on schedule.
Reply to unread messages in chat apps using your tone.
Collect material across apps and assemble a slide deck.
Plan and run multi-step tasks, turning routine work into automated AI workflows.

# How PlugClaw Protects Your Privacy (Privacy First: Hardware Isolation Plus Confidential Computing)
The approach: keep local data safe with hardware isolation, and keep cloud processing safe with confidential AI computing.
Your AI workspace, skills, memory, and files stay locked inside the device encrypted system. PlugClaw never asks the host for admin rights and never reads the host own content. When it calls a powerful cloud model, confidential computing places your data inside a hardware-protected trusted execution environment, so the plaintext never reaches the vendor or the cloud service.
The foundation is TrustKernel TEE. This hardware isolation has shipped on more than one billion devices, providing chip-level separation for payments, unlocking, and scanning. On PlugClaw, advanced cloud models and personal privacy run together.
